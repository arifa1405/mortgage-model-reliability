# Mortgage Credit-Risk Model Reliability Under Changing Borrower Populations

MS Data Science Capstone Project

## Research Objective

This project investigates whether changes in borrower populations are associated with degradation in mortgage credit-risk model reliability, and whether model-aware population drift provides more useful evidence of degradation than population drift alone.

The project studies the following chain:

Population Drift → Model-Relevant Drift → Model Degradation → Retraining Benefit

## Data

- Development dataset: Freddie Mac Single-Family Loan-Level Dataset
- External validation dataset: Fannie Mae Single-Family Loan Performance Data

## Models

- Logistic Regression
- XGBoost
